Engineering Specs

Model Architecture & Training Pipeline

How HerbalNet AI achieves state-of-the-art accuracy with lightweight parameters suitable for edge and browser deployment.

1. Input Preprocessing

224 × 224 × 3 RGB tensor normalized into [-1, 1] range matching MobileNetV2 pre-training.

Invertible Scaling

2. Augmentation Pipeline

Random flip, shear, zoom, brightness jittering & affine transforms to prevent overfitting.

8× Data Multiplier

3. MobileNetV2 + NAS

Depthwise separable convolutions + Neural Architecture Search (NAS) optimized dense block.

2.2M Parameters

4. Shannon Entropy Filter

Computes categorical entropy H = -Σ p log(p). Rejects random objects & unknown weeds.

Threshold = 2.10

Core Framework

TensorFlow 2.12+ with Keras 3.x, optimized MobileNetV2 backbone with custom Dense config handler.

Developer Setup

Local Flask Backend Quickstart

Run the high-performance local inference server with Keras 3 and hardware acceleration.

bash • git clone & run HerbalNet.AI 
# 1. Clone the repository
git clone https://github.com/DANIELRAAJ/herbalnet.ai.git
cd herbalnet.ai

# 2. Create and activate a Python virtual environment
python -m venv venv
.\venv\Scripts\activate  # Windows
# source venv/bin/activate  # macOS/Linux

# 3. Install dependencies
pip install -r requirements.txt

# 4. Launch the HerbalNet AI Flask server
python app.py

# Server ready at http://localhost:5000
